# 🎧 Sitcom & Kindle English/Japanese Study Studio

미드 영어 받아쓰기(유튜브 공식 클립 · 쿠팡플레이 · 넷플릭스), 일본어 어순 조립 받아쓰기(넷플릭스), 그리고 **킨들(Kindle for PC) 영어원서 정독 스튜디오**와 **노션(Notion) 실시간 자동 단어·문법장**을 하나로 묶은 통합 어학 학습 도구입니다.

---

## 📂 폴더 구성

| 폴더 / 파일 | 설명 |
| :--- | :--- |
| **`실행하기.bat`** / `server.ps1` | 별도 설치(Python/Node 불필요) 없이 더블클릭 한 번으로 실행되는 로컬 웹 스튜디오 서버 (`http://localhost:8765`) |

| **`netflix-dictation-extension/`** | **넷플릭스 영어 받아쓰기 크롬/엣지 확장 프로그램 (`v1.2.1`)** — 대사별 자동 멈춤, 타이핑 채점, 한·영 자막 매칭, AI 심층 해설, 정밀 이어하기, 노션 실시간 연동 |

| **`노션_자동연동_설정가이드.md`** | 2분 만에 끝나는 무료 노션(Notion) 실시간 단어·문법장 자동 저장 연결 안내서 |

## 🚀 다른 컴퓨터에서 바로 실행하는 방법 (Windows 10 / 11)

1. 이 저장소를 `git clone` 하거나 우측 상단 **`[Code] → [Download ZIP]`**으로 내려받아 압축을 풉니다.
2. **웹 스튜디오 & 📖 킨들 영어원서 동반 모드 실행**:
   - 폴더 안의 **`실행하기.bat`**을 더블클릭하면 브라우저에서 `http://localhost:8765`가 열립니다.
3. **넷플릭스 크롬/엣지 확장 프로그램 등록**:
   - 주소창에 `chrome://extensions` (엣지는 `edge://extensions`) 입력 → 우측 상단 **`개발자 모드` 켜기**
   - **`압축해제된 확장 프로그램을 로드합니다`** 클릭 → `netflix-dictation-extension` 폴더 (일본어는 `netflix-jp-dictation-extension` 폴더) 선택!
4. **노션(Notion) 단어·문법장 연동**:
   - 자세한 설정 순서는 [`노션_자동연동_설정가이드.md`](./노션_자동연동_설정가이드.md)를 참고해 주세요.

> 🔒 **보안 안내**: 입력하시는 Google Gemini / OpenAI API 키와 노션 토큰은 소스 코드에 절대 포함되지 않으며, 오직 각 컴퓨터의 브라우저 내부 저장소(`chrome.storage.local` / `localStorage`)에만 안전하게 보관됩니다.

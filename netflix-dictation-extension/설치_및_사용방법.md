# Netflix Sitcom Dictation Studio 설치 및 사용 가이드

넷플릭스(`https://www.netflix.com`) 웹 화면에서 바로 작동하는 **크롬(Chrome) / 엣지(Edge) 전용 받아쓰기 확장 프로그램**입니다.

---

## 1. 10초 설치 방법 (크롬 & 엣지 공통)

1. 브라우저 주소창에 아래 주소를 입력하고 `Enter`를 누릅니다.
   - **크롬(Chrome)**: `chrome://extensions`
   - **엣지(Edge)**: `edge://extensions`
2. 화면 우측 상단(엣지는 좌측 메뉴)의 **[개발자 모드(Developer mode)]** 스위치를 **켬(ON)**으로 바꿉니다.
3. 상단 버튼 중 **[압축해제된 확장 프로그램을 로드합니다(Load unpacked)]**를 클릭합니다.
4. 바탕화면 `영어 듣기` 폴더 안의 **`netflix-dictation-extension`** 폴더를 선택하고 [폴더 선택]을 누르면 즉시 설치됩니다!

---

## 2. 넷플릭스에서 사용하는 방법

1. 넷플릭스(`https://www.netflix.com`)에 접속해 원하는 미국 드라마(예: `<슈츠>`, `<브루클린 나인-나인>`, `<영 쉘든>`, `<굿 플레이스>`, `<길모어 걸스>` 등)를 재생합니다.
2. 넷플릭스 플레이어 우측 하단 말풍선(자막) 메뉴에서 **[영어(CC)]**를 선택합니다.
   - *한국어 해석까지 함께 보려면*: 우측 받아쓰기 패널의 **`[한·영 자막 동기화]`** 버튼을 한 번 눌러주세요! (자동으로 한국어 자막 데이터까지 읽어와 보관한 뒤 영어 자막으로 돌아옵니다.)
3. 영상 화면은 왼쪽에 깔끔하게 배치되고, **우측 사이드 패널**에 받아쓰기 스튜디오가 열립니다! (화면 가림 없이 100% 시청 가능)
4. **학습 흐름**:
   - 대사 한 줄이 끝나는 순간 **영상이 자동으로 멈춥니다.**
   - 방금 들린 영어 문장을 입력하고 **`Enter`**를 누릅니다. (다시 듣기는 **`Ctrl + Space`**)
   - 통과하면 **공식 한국어 자막 + 발음/연음 포인트 + 구동사·관용어 해설 + 문법 분석**이 즉시 열립니다.
   - 다시 **`Enter`**를 누르면 자동으로 다음 대사가 이어서 재생됩니다!
5. 그냥 편하게 드라마만 감상하고 싶을 때는 패널 상단의 **`[자동멈춤 ON]`** 버튼을 눌러 **`[일반시청 모드]`**로 바꾸거나 **`[—]`** 버튼으로 접어두실 수 있습니다.
